Drop royalty-free tracks into the mood folder they belong to:

    assets/music/eerie/     assets/music/tense/     assets/music/upbeat/
    assets/music/playful/   assets/music/wistful/   assets/music/awe/
    assets/music/neutral/

Any number of tracks per folder; one is picked at random each run. Accepted:
.mp3 .m4a .aac .wav .ogg .opus. A track shorter than the clip is looped, and
fades out at the end.

'neutral' is the fallback, so keep at least one track there.

WHERE TO GET THEM — must be genuinely licence-free for monetised use:
  - YouTube Audio Library (studio.youtube.com > Audio library) — safest,
    made for this, and no attribution needed on most tracks.
  - Pixabay Music, Free Music Archive (check each track's licence),
    Kevin MacLeod / incompetech (CC-BY, attribution required in description).

DO NOT put commercial or "trending" songs here. Trending audio can only be
added legally through the YouTube app's Shorts editor, which the Data API
cannot reach. A commercial track baked into an uploaded file gets a Content ID
claim: revenue redirected, possible regional blocking, and repeat offences
push a channel toward strikes.
